# Contributing

The full guide lives at [docs/CONTRIBUTING.md](docs/CONTRIBUTING.md).

The short version: this repo values restraint, receipts, and taste over feature count. The most-wanted contributions are new recipes with honest "When NOT to use" sections, palette seeds with AAA-verified tokens, visual identities with proof, and lessons for the learnings log. If a rule must hold, contribute the test or script that enforces it — not just the prose. See also the [Code of Conduct](CODE_OF_CONDUCT.md).
