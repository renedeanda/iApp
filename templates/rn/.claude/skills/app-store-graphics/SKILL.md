# /app-store-graphics

This app's App Store graphics are emitted by the iApp engine as **two**
self-contained HTML pages (no build step, no dependencies — open straight in Chrome):

| File | What it is |
|---|---|
| `scripts/app-store-graphics.html` | **Studio** — locale switcher; first-image / wordmark / device-frame / format toggles; per-card, per-device, and the bulk "Everything" ZIP export. |
| `scripts/app-store-graphics-simple.html` | **Simple** — a minimal static page (English): fixed caption layout, drop a screenshot, download the exact-size PNG. The "use what works" fallback, modelled verbatim on hand-crafted reference files proven in shipped apps. |

## Sizes — both Apple-approved, emitted from one layout

| Device | Sizes (px) |
|---|---|
| iPhone | 6.9" **1320×2868** · 6.5" **1242×2688** |
| iPad | 13" **2064×2752** · 12.9" **2048×2732** |

(Mac 2880×1800 is Studio-only, universal apps.)

## Use it

1. Open `scripts/app-store-graphics.html` (full control) or `scripts/app-store-graphics-simple.html` (quick) in Chrome.
2. Drop your raw app screenshots into each slot (they persist across toggle/locale changes).
3. Download a single card, a per-device ZIP, or the "Everything" archive — every
   locale x size foldered `locale/size/`, ready to drag straight into App Store Connect.

## Change copy / colour / emoji / sizes

The HTML is generated, so hand edits are overwritten on the next run. Edit this
app's entry (`APPS["{{APP_SLUG}}"]`) in
`iApp:tools/app-store-graphics/generate.py` — localized caption
copy lives in `i18n_data.py` — then re-run `python3 generate.py`. Full docs:
`tools/app-store-graphics/README.md`.

## When NOT to use

- In-app imagery — those are app assets, not store graphics.
- TestFlight-only builds — App Store Connect doesn't require screenshots for TestFlight.
