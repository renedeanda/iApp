# Support — {{APP_NAME}}

> Publish at the URL specified in App Store Connect's "Support URL" field.

## Got a question or problem?

Email us at **{{SUPPORT_EMAIL}}** with:

- What you were doing when the problem happened.
- What you expected vs what you got.
- iOS version + device model (Settings → General → About).
- The app's version (shown in Settings → About).

We read every message and reply within a few days.

## Refunds

Apple handles all App Store refunds. To request one, follow Apple's
process: <https://reportaproblem.apple.com>.

## Reporting a bug

If you have a GitHub account, you can file an issue at
**{{GITHUB_ISSUES_URL}}**. Otherwise, email works fine.

## Feature requests

Same channels. We don't promise to build everything, but we read
everything.
