# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

The short version: be kind, be patient — this repo deliberately welcomes absolute beginners — and critique work, not people. Harassment, gatekeeping ("you shouldn't build apps if you don't know X"), and bad-faith participation aren't tolerated.

Report issues by opening a GitHub issue or contacting the maintainers privately through their GitHub profile. Maintainers may remove, edit, or reject contributions and participants that violate this standard.
