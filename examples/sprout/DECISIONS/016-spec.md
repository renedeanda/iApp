# ADR 016 — Spec (abridged worked example)

- **Status:** Accepted
- **App:** Sprout
- **Authors:** worked example (Kindling)

**Problem:** People discount their own progress; big-goal tools amplify the discounting.
**Target user:** Someone mid-project (a degree, a recovery, a craft) who ends days feeling "I did nothing."
**Ambition rung:** 1 — solo, one device (CloudKit sync is a later, opt-in rung 2).

**JTBD #1:** When I finish something small I almost don't count, I want to log it in seconds, so I stop letting it vanish.
**JTBD #2:** When a day felt useless, I want to see today's wins, so I argue back with evidence.
**JTBD #3:** When a week ends, I want to see the run growing, so I feel the compounding.

**Success signal:** A user logs ≥1 win on 4+ days in their first week.
**Out of scope:** goals, categories at v1, social anything, AI anything.
**Anti-vision:** Sprout becomes a habit tracker with guilt mechanics. See 013.
