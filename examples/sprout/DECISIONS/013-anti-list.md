# ADR 013 — Anti-list

- **Status:** Accepted
- **App:** Sprout
- **Authors:** worked example (Kindling)

Sprout will never:

1. **Show a streak that can break.** Runs are celebrated while alive; a lapse simply starts a new run. No "you lost your 47 days."
2. **Ask the user to plan.** No goals, no habit setup, no coaching. Wins are logged after the fact, ever.
3. **Send more than one nudge a day**, and only if the user turned it on.
4. **Gate the core log.** Logging, viewing, exporting wins: free forever (Tier 0, per 003).
5. **Add a feed.** Wins are private proof, not content.

Derived from docs/NOT_FOR.md; the allowed mirror (celebration bursts, gentle reminders) per docs/WHATS_ALLOWED.md.
