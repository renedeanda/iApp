# ADR 012 — Haptic Vocabulary

- **Status:** Accepted
- **App:** Sprout
- **Authors:** worked example (Kindling)

## Decision

The 3 starters, mapped to Sprout's moments:

| Pattern | Fires on |
|---|---|
| `bloomOpen` | App open from the widget — the "I'm here" acknowledgment |
| `completionRing` | A win logged — the payoff tap |
| `reminderSoft` | The single optional daily nudge |

Soft cap 8 via `/earn-haptic`; a 4th (e.g. a distinct 7-day-run pattern) must be earned after real usage shows the moment deserves its own word.
