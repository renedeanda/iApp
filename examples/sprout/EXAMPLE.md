# Sprout — The Worked Example

This folder is **what Kindling produces**: the Swift template rendered exactly as `/new-app --commit` renders it, for a small fictional app called **Sprout** ("Tiny daily wins, logged in five seconds, growing into proof"). Browse it to see the output before investing an evening in the wizard.

## What to look at

| Look at | What it shows |
|---|---|
| `DECISIONS/` | Eleven worked ADRs — what good wizard answers look like (mission, palette departure, motion restraint, anti-list, abridged spec) |
| `CLAUDE.md` | The per-app constitution with every `{{placeholder}}` filled from those ADRs |
| `Sprout/Theme/AppTheme.swift` | The Sage seed *departed* — diff it against `templates/swift/Seed/Theme/AppTheme.swift` to see exactly what a palette decision changes |
| Everything else | Identical in shape to the template — which is the point: the wizard's work is naming, palette, and decisions; the engineering is inherited |

## Run it

```sh
cd examples/sprout
xcodegen generate
open Sprout.xcodeproj    # ⌘R
```

## Don't build on it

Sprout is a reference, not a starting point — start your own app per [docs/YOUR_OWN_REPO.md](../../docs/YOUR_OWN_REPO.md) and the wizard (or `make bootstrap`) so your name, bundle ID, and decisions are yours.

## Maintenance

Generated by `scripts/render-sprout-example.sh` (rename + palette + placeholder fill; `DECISIONS/` and this file are hand-written and preserved). Re-run it after any `templates/swift` change so the example never drifts.
