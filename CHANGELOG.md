# Changelog

All notable changes to Kindling — the templates, recipes, skills, and docs. Format follows [Keep a Changelog](https://keepachangelog.com); versions follow semver-ish pragmatism: **major** = a template or wizard change that alters rendered apps' structure, **minor** = new recipes/skills/docs or additive template features, **patch** = fixes and wording.

**If you `git pull` this repo for updates** (the [two-repo workflow](docs/YOUR_OWN_REPO.md)): read the entries since your last pull before adopting anything. Template changes never rewrite your existing apps — they affect the *next* render; adopt improvements into shipped apps deliberately, recipe-style.

Maintainers: tag each released version (`git tag v0.x.y && git push --tags`) and cut a GitHub Release pasting that version's section, so watchers get notified.

## [0.1.0] — 2026-07-25

Initial open-source release. Everything is new, so highlights only:

### Added
- **Swift template** — XcodeGen + SwiftUI + SwiftData scaffold: StoreKit 2, widget + Live Activity extension, App Intents, services disabled-by-default, theme/typography/motion/delight token systems, 24-pattern haptic reference, housekeeping test suite (contrast, localization parity, privacy manifests, motion wiring), fastlane.
- **React Native template** — Expo + Expo Router scaffold: 7-locale i18n, iCloud-sync Expo module, rolling-64-limit notification service, theme registry, parity test suite.
- **The wizard** — `/new-app` 21-step design-first flow with mandatory overnight pause, mockup intake (static exports or connected design-tool MCP), ambition-rung classification, and render-into-your-own-repo.
- **50+ recipes** with "When NOT to use" sections; **30+ agent skills**; `/start` concierge.
- **Portfolio layer** — starter PORTFOLIO, 10-seed palette catalog, 5-tier monetization ladder, reuse index, pre-seeded learnings log.
- **Beginner on-ramp** — first-app tutorial, glossary, idea worksheet, setup + device/TestFlight guides, landing-page starter, ambitious-apps guide.
- **Multi-agent support** — CLAUDE.md (Claude Code) + AGENTS.md (Codex and friends), skills mirrored at `.agents/skills/`.
- **Tooling** — App Store graphics generator, launch-packet schema, CI verify scripts, MIT license, community files, showcase.
- **Worked example** — `examples/sprout/`: the Swift template rendered end-to-end for a fictional app with eleven worked ADRs, regenerated by `scripts/render-sprout-example.sh`.
- **Post-launch guide** — `docs/AFTER_1_0.md`; **docs index** — `docs/README.md`; this **CHANGELOG** + release ritual.
